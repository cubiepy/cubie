Using the solver

Once you have defined an ODE system (see Defining systems), CuBIE provides two ways to solve it: the convenience function solve_ivp() and the reusable Solver class.

Cubie can build the batches you want to solve over (see Inputs and Parameter Sweeps), and provides results in a number of formats (see Working with Results). You’ll usually want to modify the timing parameters to suit your integration (see Timing Parameters), and deeper configuration is achievable (see Configuration Reference).
