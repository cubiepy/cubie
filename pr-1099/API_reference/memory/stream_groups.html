StreamGroups

class cubie.memory.stream_groups.StreamGroups(groups: dict[str, list[int]] | None = NOTHING, streams: dict[str, stream | int] = NOTHING)[source]

Bases: object

Container for organizing instances into groups with shared streams.

Parameters:

  • groups (dict[str, list[int]] | None) – Dictionary mapping group names to lists of instance identifiers. When omitted, an empty mapping is created and populated with the “default” group.

  • streams (dict[str, cubie.vendored.cudasim.api.stream | int]) – Dictionary mapping group names to CUDA streams. When omitted, each group, including “default”, receives a dedicated stream from numba_cuda_mlir.cuda.stream() on first use. No group is ever backed by the device-wide default stream, so work in one process never orders against the CUDA null stream.

Notes

Each group has an associated CUDA stream that all instances in the group share for coordinated operations. The “default” group is created automatically.
