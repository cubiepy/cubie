Variables

When you parse a system, you get its states, parameters and observables as a VariableSet ordered by name. States and parameters keep their default values in a ValuedSet. A ParameterSet also records whether you sweep each parameter in a batch solve or fix it at a value, and you get a new one for each combination of swept parameters and fixed values you solve with.

Bases: Variable

A parameter that is either swept or fixed at a value.

The generated code reads a swept parameter from the parameters array in each run, and writes a fixed parameter’s value into the source as a constant. Give a swept parameter no value, and give a fixed parameter its value.

Parameters:

  • swept (bool) – True to read the parameter from the parameters array in each run.

  • value (float | None) – The value of a fixed parameter, or None for a swept parameter.

Raises:
