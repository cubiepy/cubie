BaseODE

class cubie.odesystems.BaseODE(precision: type[float16] | type[float32] | type[float64] | dtype[float16] | dtype[float32] | dtype[float64], parameters: ValuedSet, specialiser: CUDAFactory, initial_values: Mapping[str, float] | None = None, operation_ordering: str = 'liveness_auto', name: str | None = None)[source]

Bases: CUDAFactory

Abstract base for CUDA-backed ordinary differential equation systems.

Subclasses override build() to compile a CUDA device function that advances the system state and, optionally, provide analytic helpers via get_solver_helper(). The base class handles value management, precision selection, and caching through CUDAFactory.

Notes

Only functions cached during build() (typically dxdt) are available on this base class. Solver helper functions such as the linear operator or preconditioner are generated only by subclasses like SymbolicODE.

BaseODE keeps parameter defaults and initial values outside its compile settings, so it rebuilds only when a new default changes a value compiled into the code.

Parameters:

  • precision – Precision factory used for calculations.

  • parameters – The parameters with their defaults.

  • specialiser – Child factory holding the compiled_parameters setting, every parameter swept or fixed at a value, and building the layout, mass and equations of the system assembled for them.

  • initial_values – Default initial values by state name. States left out start from 0.0.

  • operation_ordering – Generated-operation ordering policy: "liveness_auto", "kahn", "greedy", or "dfs". Defaults to CUBIE_OPERATION_ORDERING (liveness_auto when unset).

  • name – Printable identifier for the system. Defaults to None.
