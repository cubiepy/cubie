BackwardsEulerPCStep

Defaults

algorithm="backwards_euler_pc" inherits every default from BackwardsEulerStep — order 1, fixed-step control, and the shared Newton–Krylov solver settings (Default settings) — adding only an explicit forward-Euler predictor evaluated before the implicit corrector runs.
