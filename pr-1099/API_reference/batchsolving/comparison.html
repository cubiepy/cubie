class cubie.batchsolving.comparison.ComparisonRunner(solver: Any, inits: Any = None, params: Any = None, duration: float = 0.0, settling_time: float = 0.0, t0: float = 0.0, verbose: bool = False, max_parallel: int = 4)[source]

Bases: object

Switch one solver between candidates and time each on one batch.

The batch stays on the device; candidates apply over the configuration at open(), which close() restores.

Parameters:

  • solver – The solver whose settings the candidates vary.

  • inits – The (variable, run) grid to time on; None compiles only.

  • params – The (variable, run) grid to time on; None compiles only.

  • duration – Integration window of the timed solves.

  • settling_time – Integration window of the timed solves.

  • t0 – Integration window of the timed solves.

  • verbose – Print progress lines.

  • max_parallel – Maximum compilations to run in parallel.

time(candidates: Sequence[Candidate]) → List[CandidateTiming][source]

Time every candidate on the staged batch, forward then back.

Every candidate solves SOLVES_PER_ROUND times in each of ROUNDS rounds; the second round reverses the order. A rejected or failing candidate carries the error and no times.

cubie.batchsolving.comparison.rank_timings(timings: Sequence[CandidateTiming]) → List[CandidateTiming][source]

Order timed candidates: the top success tier by time, then the rest.

The top tier holds every candidate whose success rate is at least SUCCESS_TIER_FRACTION of the best success rate.
