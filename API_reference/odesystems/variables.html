Variables

A system declares its states, parameters and observables as frozen records held in ordered sets. A set’s order is the row order of every array that holds one value per variable. A ParameterSet holds each parameter as the current batch compiles it: swept, so each run reads it from the parameters array, or fixed at the value compiled into the code.

class cubie.odesystems.variables.ParameterSet(entries)[source]

Bases: VariableSet

The parameters as a batch compiles them.

We hold one CompiledParameter per parameter, in the system’s parameter order, and fill the parameters array with one row per swept parameter in that same order. We keep no defaults here, so a default reaches the build only as the value of a fixed parameter.

Parameters:
